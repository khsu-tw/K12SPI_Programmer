燒錄速度

  • 抹除會自動選最大的對齊區塊（64KB → 32KB → 4KB），比逐一 4KB 快很多。
  • 頁寫入採流水線：傳下一頁資料的同時，flash 正在寫上一頁；全空白（0xFF）的頁會略過。
  • 驗證以每 64KB 比對板上 CRC，不需把資料讀回 PC；SPI clock 設為 Max 最快（不穩時用 Link Test）。
  • 檔案超過晶片容量的一半時可勾選「Chip Erase first」（資料全清）。Chip Erase 逾時依資料手冊最大值：MX25S1633F 57 s（Ultra Low Power 模式的最大值）、GD25UF16E 50 s、W25Q65NE 140 s、W25Q32NE 70 s。

第一次使用的建議順序

  1. 先不接 flash：只接 USB-C，燒好 Nano 韌體（firmware/flash_nano.bat；用 MPLAB IPE 燒錄並回讀驗證，最後一行應為 Programmed and verified。不要用拖放到 CURIOSITY 磁碟機：PIC18F16Q20-CNANO 上 5.0.0 的 HEX 會被截斷，且 STATUS.TXT 仍顯示 Ready），GUI 按 Connect。出現 Bridge alive. 表示通訊正常；這時 ID:FF FF FF 是正常的。
  2. 斷電接線：依 HARDWARE.md 接好 TXS0108E 與 1.2V LDO，先不放 flash。上電後用電表確認 VCCA、OE、flash 座 pin 8 都是約 1.2V，flash 座任何一腳都沒有 3.3V。
  3. 放入 flash：SPI clock 先選 Slow → Connect → 應出現 Detected Macronix MX25S1633F ...（換其他晶片則顯示對應型號）；穩定後再用 📶 Link Test 找最快的設定。

一般燒錄流程

  1. Connect → Log 會出現 Bridge alive. 和 Detected <廠牌> <型號> ...
  2. （建議）先備份：Address 000000、Length 用 Auto Detect 自動帶入的整顆容量（例如 2MB = 200000）→ 💾 Read→File。
  3. 📂 Load File… 選擇燒錄檔。.hex 會自動帶入起始位址；.bin 預設從 0x000000 開始。
  4. 確認 Address → 按 📥 Program (loaded)。
  5. 勾選「Verify after program」的話，燒完會自動驗證，最後顯示 VERIFY OK。

Status Register（Config SR）

SR1（05h）的位元定義三家不同，GUI 依偵測到的晶片自動切換：

BitMX25S1633FGD25UF16EW25Q65NE / W25Q32NE
7SRWD：SR 寫入保護SRP0：SR 保護SRP：SR 保護
6QE：Quad Enable（=1 時 WP#/RESET# 變 SIO2/SIO3）BP4SEC：保護單位 4KB 扇區(1) / 64KB 區塊(0)
5BP3BP3TB：從頂端(0) / 底端(1) 保護
4~2BP2~BP0BP2~BP0BP2~BP0
1WEL：唯讀，Write Enable LatchWELWEL
0WIP：唯讀，Write In ProgressWIPBUSY
  • SR2（35h，只有 GD25UF16E 與 Winbond）：GD25UF16E 為 SUS1、CMP、LB3~LB1、SUS2、QE、SRP1；Winbond 為 SUS、CMP、LB3~LB1、QE、SRL。Config SR 只改 SR1，但會把 SR2 原值一併寫回：GD25UF16E 只寫 1 個位元組時會把 SR2 的可寫位元清 0。LB3~LB1 是 OTP，設成 1 就無法復原，GUI 不提供修改。
  • 保護區域的對照表請見各晶片資料手冊（DOC/）的 Memory Protection 表；GD25UF16E 與 Winbond 另受 SR2 的 CMP 影響（CMP=1 時保護範圍反轉）。
  • 勾選後右上角會即時顯示 SR 數值；按 Default 全部清 0；按 OK 會執行 WREN → WRSR → 讀回比對。
  • 只要 BP 位元不是全 0（或 CMP 造成任何區域受保護），Chip Erase 就不會執行，被保護的區域也無法抹除或燒錄。燒錄失敗時請先把 BP 位元清 0。
  • 如果 SRWD / SRP0 / SRP=1 導致寫不進去：先勾 WP# High（需要接 WP# 線），再改 SR。GD25UF16E 的 SRP1=1、Winbond 的 SRL=1 為電源鎖定，需斷電重上電才會解除（GD25UF16E 也可用軟體重置 66h+99h）。
  • W25Q32NE 的 SR 位元與 W25Q65NE 相同（依 DOC/ W25Q32NE 資料手冊 RevE）。
  • W25Q64NE 不支援：它與 W25Q65NE 的 JEDEC ID（EF 65 17）與容量（64Mbit）相同，無法區分，插入時會顯示為 W25Q65NE。兩者的 Chip Erase 最大時間（160 s / 140 s）、tRES1（50 µs / 20 µs）、最高讀取時脈（33 MHz / 84 MHz）不同，若使用 W25Q64NE 請自行確認。

燒錄必要參數與 JESD216H（SFDP）欄位對照

依據 DOC/ 下的三份資料手冊（MX25S1633F Rev.1.3、GD25UF16E Rev1.0、W25Q65NE_DTR RevD）與 DOC/JESD216H.pdf。本燒錄器只用 1-1-1（單線）SPI、3-byte 位址、03h Read、02h Page Program，所以 Quad / DTR / QPI 等欄位不列入必要項目。

必要性：

  • 必要：燒錄程式缺了它就無法正確讀寫或抹除。
  • 安全：設錯會損壞晶片或把晶片鎖住。
  • 選用：可以改善行為，但不影響基本燒錄。

SFDP 欄位代號：DWn[x:y] = JEDEC Basic Flash Parameter Table（ID FF00h）第 n 個 DWORD 的第 x–y 位元；條號為 JESD216H 的章節。

8. 從這張表看出的問題與處理

  • Deep Power-Down（已處理，韌體 5.1.0）：三顆都支援 B9h / ABh，原本韌體不送 ABh，晶片若在省電模式 ID 會讀成 FF FF FF。現在韌體開機與 GUI Auto Detect 都會先送 ABh。實測 W25Q32NE：ABh 之後的第一筆 SPI 傳輸讀到全 0，第二筆才正確，原因未查明，韌體在 ABh 後多做一次 RDSR 吸收掉。
  • MX25S1633F 的 ULP 模式（已處理）：MX25S1633FM2IG2 出廠預設是 Ultra Low Power 模式，Chip Erase 最大 57 s。chip_erase_s 已由 38 s 改為 57 s（GUI 等待 77 s）。
  • GD25UF16E 的 QE：QE 固定為 1、不能改（資料手冊 6.1 QE bit），但手冊也註明「WP# pin is still available for Standard/Dual SPI」。本燒錄器只用 1-1-1 單線 SPI，所以 WP# 與 SRP0 硬體保護仍然有效，GUI 的「WP# High」照常需要。
  • GD25UF16E / W25Q65NE 的 SFDP：還沒讀過實機，上板後請比對 Log 的 SFDP: 行與本表。
